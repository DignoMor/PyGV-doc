# API Reference

The signatures and defaults on these pages are generated from the pinned code
revision recorded in {doc}`../provenance`, not from a released distribution.

```{toctree}
:maxdepth: 2

viewer
tracks
utilities
```

- {doc}`viewer` documents `GenomeViewer`, which owns track order, figure
  layout, shared annotations, and the render lifecycle.
- {doc}`tracks` documents every class exported by `pygv.tracks`, including its
  inherited configuration fields, defaults, accepted literals, and
  compatibility aliases.
- {doc}`utilities` documents the public utility functions.
